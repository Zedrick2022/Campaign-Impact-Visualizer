## IMPORTANT — first-time activation
1. Upload the folder to your website / GitHub Pages.
2. Open the live landing page.
3. Submit the form once using a test name and email.
4. FormSubmit will send an activation/confirmation email to zedricksalupito@gmail.com.
5. Open that email and confirm/activate the form.
6. Test the form again after activation.

Until the owner email has been confirmed, normal delivery may not work.

## Hosting on GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open Settings → Pages.
4. Choose "Deploy from a branch".
5. Select the main branch and root folder.
6. Save and wait for your GitHub Pages URL.
7. Visit the live page and complete FormSubmit activation.

## Customising the page
- Change text in index.html.
- Change the visual design in style.css.
- Change validation/loading behaviour in script.js.
- Keep the email form as a normal HTML POST if you want FormSubmit autoresponse to work.

## Security note
No Gmail password or secret API key is stored in this website.
